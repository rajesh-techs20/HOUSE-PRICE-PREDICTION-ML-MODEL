# 🏠 House Price Prediction

A Machine Learning web application built using Python, Scikit-learn, and Streamlit.

## Features
- Predict house prices
- User-friendly interface
- Dataset preview
- Charts and statistics
- Linear Regression model

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Matplotlib
